# DevOps Roadmap — Zero to Hired

A beginner-friendly, 14-week DevOps learning roadmap — from Linux fundamentals to one deployable, observable cloud project, at 3 hours a day.

🔗 **Live site:** https://devops.ashuxd.me

## What's inside

- **5 phases · 14 weeks** — Linux, Bash + Git, Networking + YAML, Docker, CI/CD, AWS, Kubernetes, Terraform, Monitoring, Capstone, and interview prep
- **Build every week** — each week ends with a hands-on task and a "done when" checklist, not just videos to watch
- **Interview drill** — explain-it-out-loud questions plus a 230-question PDF bank covering Docker, Kubernetes, and Terraform
- **Bold Memphis-style UI** — single-page site, fully responsive

## Project structure

```
├── index.html               # The entire website (single file)
└── interview-questions.pdf  # 230 DevOps interview Q&A — Docker, Kubernetes, Terraform
```

## Deployment

Deployed on [Vercel](https://vercel.com) with a custom domain (`devops.ashuxd.me`). Every push to `main` auto-deploys.
